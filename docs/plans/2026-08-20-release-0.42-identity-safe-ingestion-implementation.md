# Codemem 0.42 Identity-Safe Ingestion: Implementation Plan

**Design:** [Codemem 0.42: Identity-Safe Ingestion](./2026-08-20-release-0.42-identity-safe-ingestion-design.md)
**Status:** Approved for implementation
**Date:** 2026-08-20

## PR 1: Identity-safe raw-event ingestion

1. Extract or expose the existing pack-route database and identity comparison
   policy without changing its behavior.
2. Add failing viewer-route tests for database mismatch, identity mismatch,
   unsupported contracts, path equivalence, omitted fields, and no partial writes.
3. Apply the guard to canonical raw events and Claude/Codex compatibility routes
   before ingestion begins.
4. Add targeting fields to OpenCode, Claude, and Codex viewer requests.
5. Add client tests proving mismatch conflicts use the existing fallback exactly
   once and successful viewer requests do not.
6. Run targeted tests, TypeScript, lint, the full test suite, and review.

## PR 2: Candidate validation evidence

1. Exercise the local two-profile port-collision scenario and record sanitized
   outcomes.
2. Verify compatibility for requests that omit targeting fields.
3. Run packaged plugin smoke and relevant Claude/Codex transport tests.
4. Run device-identity and recipient-bound sync tests and applicable E2E suites.
5. Run `pnpm run check` and `pnpm build` on the candidate.
6. Record only reproduced evidence and document any accepted limitations.

## PR 3: Release preparation

1. Apply the shared version bump with
   `pnpm run release:version -- set 0.42.0`.
2. Run `pnpm install` and `pnpm build` to regenerate managed artifacts.
3. Verify version alignment and the public npm registry configuration.
4. Run the exact candidate gate again on the bumped commit.
5. Submit the complete Graphite stack without tagging.

## Release completion

After review and CI, merge the stack from the bottom. Update local `main`, verify
the merged release commit and clean worktree, run `pnpm run release:preflight-tag`,
then tag `v0.42.0` from merged `main` only.
